三步完成接入

① 启用采集能力

本程序用 GitHub 成熟方案 WeChatFerry（wcferry）监听你指定群里的文件消息。 需要先启用开关、安装 Python 客户端。

② 微信登录

微信扫码必须在电脑版微信里完成，程序不能也不应该代替你登录： 启动 微信 PC 3.9.x → 手机扫码确认 → 启动 WeChatFerry 客户端（本地 RPC 端口 10086）。 当前新版微信 4.x 暂不被 WeChatFerry 支持，若你是 4.x 请继续用 QQ 群文件通道。
登录成功后即可拉取你的群清单

③ 选择群并开始监听群文件

只监听你勾选的群，绝不全量监听、绝不读取加密聊天数据库； 群文件消息会自动并入资源库，和 QQ 群文件一起分类检索。
能力与限制说明（点击展开）
· 微信没有开放「列出群文件全目录」的接口，本通道是监听式采集：只有监听开启后群里新出现的文件消息会被登记；
· 历史群文件、云端未下载文件、群归属与发送者上下文不可获取；
· 聊天数据库加密，程序不读取；只接收你指定群内的文件/附件消息；
· 需要自行确认遵守微信平台规则与当地法律；本项目只做本地、授权、只读式采集。
