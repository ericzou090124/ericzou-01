技术来源与边界

借鉴（只取设计思想，零运行时依赖）：
· guiwei（MIT）— 不预设目录树、模态 + 文档体裁、vocab 别名归一、dry-run / 可撤销、敏感件闸门
· RAG-In-A-Box — Taxonomy 受控词表、语义匹配、可 CRUD
· FolderFox — 预览方案后再执行、可撤销
· WeChatBridge — 不读数据库、不注入的本地归档通道
不采用 im-mcp：它从微信进程内存提取密钥并解密 SQLite 聊天库，与本仓库「绝不读取加密聊天数据库、不解密、不注入」的隐私边界冲突。
全部规则用 Python 标准库；jieba / LLM 只是可选增强，缺失或失败静默回退到可解释的规则层。敏感件（密码 / 身份证 / 银行卡等）永不送模型。
