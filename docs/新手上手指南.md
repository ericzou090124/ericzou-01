# 新手上手指南（不用懂原理，照着点就行）

本指南面向**第一次用、且从没配置过任何东西**的你。整个程序的目标就是：把你授权可见的 QQ 群文件，整理成一个能逐级浏览、能预览、能下载、能问 AI 的本地资源库。你不需要理解背后的技术，只要完成下面 3 步。

---

## 第 0 步：准备环境（一次性）

1. 安装 **Python 3.10 或以上**。
   - 下载：https://www.python.org/downloads/
   - Windows 安装时**务必勾选「Add python.exe to PATH」**。
2. 拿到程序后，进入 `resource-manager` 文件夹，**双击 `install.bat`**（Mac / Linux 运行 `bash install.sh`）。
   - 它会检查 Python，问你要不要装「可选增强」（建议选 Y，装一下 PDF 正文抽取和本机二维码渲染），然后自动启动程序。
   - 看到浏览器打开 `http://127.0.0.1:8787` 就成功了。

> 没有 Python、或双击没反应？看上面的第 1 点重装 Python 并确认勾选了 PATH。

---

## 第 1 步：安装并登录 NapCat（唯一需要你动手的外部工具）

本程序通过 **NapCat** 读取你的 QQ 群文件。它是个**本地小程序**，用你手机 QQ 扫码登录，**不保存你的账号密码**，只在你自己的电脑上运行。

1. 打开 NapCat 官网 **https://napneko.github.io/** ，下载 Windows 一键包
   `NapCat.Shell.Windows.OneKey.zip`（已内置 QQ，不用再单独装 QQ）。
2. 解压后双击 `napcat.bat` 启动。
3. 按控制台提示，**用手机 QQ 扫一扫**完成登录。
4. 二维码直接显示在资源管理器的「QQ 登录」页面上（v3.0.0 起），扫码确认后自动恢复在线来源 —— **保持 NapCat 运行着就行**，不需要打开任何 NapCat 控制台。

> 这一步是「让程序能连上你的 QQ」的唯一前提。登录态会过期，过期了没关系：程序界面右上角点「QQ 登录」会弹出网页二维码，手机扫码即可，不用再折腾 NapCat 控制台。

---

## 第 2 步：填你要管理的 QQ 群（程序会自动弹向导）

首次打开 `http://127.0.0.1:8787` 时，顶部会出现**「首次配置」横幅**，点「开始配置」进入向导：

- **第 1 步 · 装 NapCat**：向导会检测本机 NapCat 是否已运行（就是上一步做的事）。装好并登录后点「下一步」。
- **第 2 步 · 填 QQ 群**：
  - 点「① 自动列出我的群并勾选」——程序会列出你 QQ 里所有的群，勾选你想管理的那些即可；
  - 或者手动填写：每行一个，格式 `群显示名,群号`，例如 `考研资料群,123456789`。
  - 点「保存并继续」。
- **第 3 步 · 完成**：点「打开登录页并进入主界面」，用手机 QQ 扫码，等几秒自动跳回主界面，就能看到你的群文件了。

> 配置只写进本地的 `config.json`，不会上传。以后想加 / 减群，直接再跑一遍向导，或手动改 `config.json` 里的 `sources.qq.groups`。

---

## 第 3 步：日常怎么用

界面是「三栏 + 下钻」结构，所见即所得：

- **逐级浏览**：左栏「分类大纲」或中间卡片，按 `领域 → 科目 → 资源类型`（如 `学习 → 高等数学 → 真题试卷`）逐层点开；面包屑可回退。
- **预览文件**：点任意文件的「预览」，右栏显示它的来源、分类、体积、上传时间；**还没下载的文件会明确写着「仅元数据，未下载，无正文摘要」**。
- **下载（需你确认）**：
  - 单个：预览面板「下载此文件」；
  - 多个：勾选后「下载已选」；
  - 整类：当前节点「整类下载」，需原样输入节点名二次确认。
  - **任何下载都必须你点确认，没确认程序绝不会下载任何东西。**
- **问 AI**：右侧「AI 助手」里口语化提问，例如「有哪些高数真题还没下载？」回答下方会给出**可点击的源文件索引**。没查到会如实说没检索到，不会瞎编。

## 常见问题

| 现象 | 怎么办 |
| --- | --- |
| 界面提示「离线快照 / 未连接」 | QQ 登录态过期了。点右上角「QQ 登录」→ 网页扫码 → 自动恢复。 |
| 二维码打不开 / 取不到 | 点登录页「刷新二维码」，会自动拉起 NapCat 并向 QQ 申请新码；仍不行就双击 `tools/setup_napcat.bat` 查看安装自检报告与自动修复结果。 |
| 群文件列表是空的 | 第 2 步没填对群号，或 NapCat 还没扫码登录；重跑向导或点「刷新来源」。 |
| 想用 Obsidian 看笔记 | 用 Obsidian「打开文件夹作为库」选择 `桌面/资源管理/`，右侧栏有「资源 AI 搜索」。 |
| 想换 / 加 QQ 群 | 重跑「首次配置」向导，或编辑 `config.json` 的 `sources.qq.groups`。 |
| PDF 看不到正文摘要 | 没装 PyMuPDF。双击 `install.bat` 重跑并选装可选增强即可。 |

## 安全性与隐私（你可以放心）

- 程序**只读取你授权可见的群文件元数据**，绝不移动、删除、重命名任何源文件。
- 所有网络只监听本机 `127.0.0.1:8787 / :3000`，**不上传任何数据到外部服务器**。
- AI 默认用你本地模型；若配外部 API，密钥只存本机 `state/secrets.json`，不进仓库。
- 个人微信没有开放接口、聊天库加密，本期无法接入；界面已如实说明并预留接口。
