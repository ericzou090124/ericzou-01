## 6. 给第一次使用的人

仓库下载下来是一份源码包（或 GitHub Release 附件 `resource-manager-vX.Y.Z.zip`）。按下面做即可，**不需要理解任何原理**：

1. **先解压整个压缩包到一个文件夹**（例如桌面新建「资源管理」文件夹，把里面所有文件放进去），**不要**在 .zip 里直接双击 `install.bat`。然后进入该文件夹，双击 `install.bat`（Mac / Linux 运行 `bash install.sh`）。它检查 Python、按需装可选增强、自动启动服务并打开 `http://127.0.0.1:8787`。
2. 第一次打开会弹出「首次配置」横幅 → 点「开始配置」进入向导：
   - 第 1 步：按向导里的链接装好 NapCat（QQ 机器人，必需），用手机 QQ 扫码登录；
   - 第 2 步：在向导里「自动列出我的群」勾选，或手动填群号，保存。
3. 向导完成后自动跳回主界面，就能看到并管理你的 QQ 群文件了。

压缩包里的 `新手必读.txt` 与 `docs/新手上手指南.md` 是同一份引导，随时可看。详细的图文步骤、常见问题、安全隐私说明都在 `docs/新手上手指南.md`。

## 5. 已知限制（详见 VERIFICATION.md 第 5 节）

1. 个人微信无开放 API / 无协议端 / 聊天库加密，不能复现 QQ 接入；只能看到本地已落地文件。
2. 未下载文件只有元数据，没有正文摘要；要内容必须先显式确认下载。
3. 整类下载单批上限 30 个文件；超出需再次确认。
4. 扫描版 PDF / 老格式 Office / zip 只登记元数据，无正文。
5. 浏览器 GUI 未做自动化点击验证，本次以 HTTP + API + 端到端链路验证为主，建议人工目视确认一次。
6. 本地 Bonsai2 常驻显存约 7.3 GB；模型未启动时 AI 自动降级为纯本地检索。
