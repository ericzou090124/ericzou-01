## 1. 这次交付了什么

一个完整闭环的本地「资源管理」程序：QQ 群文件只读盘点 → 三级分类目录 → 可视化逐级下钻 / 预览 → 显式确认下载 → 自动入库、摘要、多级大纲 → Obsidian 新库 AI 检索。

- **统一资源库**：`桌面/资源管理/`（新建独立 Obsidian 库，原有库不动）
- **界面**：`http://127.0.0.1:8787`，双击 `start.bat` 启动
- **QQ 接入**：本机 NapCat OneBot 11，三群实时遍历 1641 条，去重后 1625 条 / 12.73 GB
- **微信**：评估后确认不可复现 QQ MCP 流程，本期只做限制说明与预留适配器

## 3. 验收清单（可逐项勾选）

- [ ] `python server.py` 或双击 `start.bat` 能启动，`/api/health` 返回 `ok=true`
- [ ] 浏览器打开 `http://127.0.0.1:8787` 出现三栏界面；左栏 QQ 显示「在线」、微信显示「未接入」
- [ ] 点击 `学习 → 高等数学 → 真题试卷` 能逐级下钻，面包屑可回退
- [ ] 点「预览」能看到元数据；未下载条目明确写「仅元数据，未下载，无正文摘要」
- [ ] 勾选文件 → 下载已选 → 确认弹窗 → 下载后原文件与笔记出现在 `资源管理/资源/`、`资源管理/笔记/`
- [ ] 整类下载需原样输入节点名，输错会被拒绝
- [ ] 未确认 / 空 ids / 离线快照三种情况下载被服务端拒绝
- [ ] 提问「有哪些高数真题还没下载？」→ 返回份数、体积、代表文件名，并标注仅元数据
- [ ] 提问「量子纠缠超导材料制备工艺」→ 如实返回未命中，无来源
- [ ] 「设置」里能切本地模型 / 外部 API，能测试连接；密钥不回显
- [ ] Obsidian 打开 `桌面/资源管理/` 作为新库，右侧栏出现「资源 AI 搜索」，回答下方有可点击源文件索引
- [ ] GitHub 仓库 `ericzou-01` 的 `main` 分支含全部代码与文档，且**不含** `state/`、密钥、下载的群资料

## 5. 已知限制（详见 VERIFICATION.md 第 5 节）

1. 个人微信无开放 API / 无协议端 / 聊天库加密，不能复现 QQ 接入；只能看到本地已落地文件。
2. 未下载文件只有元数据，没有正文摘要；要内容必须先显式确认下载。
3. 整类下载单批上限 30 个文件；超出需再次确认。
4. 扫描版 PDF / 老格式 Office / zip 只登记元数据，无正文。
5. 浏览器 GUI 未做自动化点击验证，本次以 HTTP + API + 端到端链路验证为主，建议人工目视确认一次。
6. 本地 Bonsai2 常驻显存约 7.3 GB；模型未启动时 AI 自动降级为纯本地检索。
