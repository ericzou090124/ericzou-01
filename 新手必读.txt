资源管理 · 新手必读（零配置上手）
================================

一、最重要的一步：下载后直接双击安装器即可
------------------------------------------
从 GitHub Release 下载的只有一个文件：
    resource-manager-installer.bat

**直接双击它就行**，不用解压、不用手动操作。
无论你是在压缩包预览里双击，还是先解压再双击，它都会：
  - 自动把程序解压到你的用户目录（C:\Users\你的名字\resource-manager）
  - 自动检查 Python、装好可选增强、启动本地服务、打开浏览器

如果系统弹窗问「是否允许」，点「允许 / 运行」即可。

二、一键安装与启动
------------------
双击 resource-manager-installer.bat：
  - 自动检查 Python（需 3.10+，且已加入 PATH；没装会弹窗提示你装）
  - 询问是否安装可选增强（PDF 正文抽取 / 本机渲染二维码），建议装
  - 启动本地服务（独立窗口，关掉本启动窗口不影响服务）
  - 自动打开浏览器到 http://127.0.0.1:8787

安装好之后，程序就安静地待在：
    C:\Users\你的名字\resource-manager
以后想再启动，进这个文件夹双击 start.bat 即可。

三、登录 QQ（扫码导入群文件）
---------------------------
双击「一键登录.bat」→ 浏览器打开扫码页 → 手机 QQ 扫码并确认。
若页面提示未连接 NapCat：先双击 tools\start_napcat.bat 启动网关，
等 10~40 秒后再刷新页面；也可以直接点界面上的「启动 NapCat」按钮。

四、日常使用
------------
  - 主界面：http://127.0.0.1:8787
  - 停止服务：双击 tools\stop.bat，或关掉名为 python 的服务窗口
  - 重新启动：双击 start.bat（在 C:\Users\你的名字\resource-manager 里）

五、常见问题
------------
  Q：双击后命令行一闪而过 / 闪退？
  A：多半是 Python 没装或没加入 PATH。先装 Python 3.10+，
     安装时务必勾选「Add python.exe to PATH」；没装的话安装器会弹中文窗提示你。

  Q：提示「解压安装包失败」？
  A：极少出现，通常是权限问题。请右键安装器选「以管理员身份运行」再试一次。

  Q：扫码后页面加载失败？
  A：服务运行在独立窗口，关掉「启动器」窗口不影响它。
     若仍打不开，确认服务窗口还开着，或进程序文件夹双击 start.bat 重启服务。
