资源管理 · 新手必读（零配置上手）
================================

一、最重要的一步：先把压缩包完整解压
------------------------------------
Windows 有个坑：如果你在压缩包里直接双击 install.bat，
系统只会把那一个 .bat 文件抽到临时目录运行，
而 tools/、server.py 等其余文件并不会被一起抽出来，
于是就会报「找不到文件 / can't open file」。

正确做法（只需一次）：
  1) 右键下载好的 resource-manager-v1.2.3.zip
  2) 选「全部解压 / 解压到...」，解压到一个空文件夹
  3) 进入解压后的文件夹，双击里面的 install.bat

解压后的文件夹里必须同时存在：install.bat、server.py、tools\ 这三个。

二、一键安装与启动
------------------
双击 install.bat：
  - 会自动检查 Python（需 3.10+，且已加入 PATH）
  - 询问是否安装可选增强（PDF 正文抽取 / 本机渲染二维码），建议装
  - 启动本地服务（独立窗口，关掉本启动窗口不影响服务）
  - 自动打开浏览器到 http://127.0.0.1:8787

三、登录 QQ（扫码导入群文件）
---------------------------
双击「一键登录.bat」→ 浏览器打开扫码页 → 手机 QQ 扫码并确认。
若页面提示未连接 NapCat：先双击 tools\start_napcat.bat 启动网关，
等 10~40 秒后再刷新页面。

四、日常使用
------------
  - 主界面：http://127.0.0.1:8787
  - 停止服务：双击 tools\stop.bat，或关掉名为 python 的服务窗口
  - 重新启动：双击 start.bat

五、常见问题
------------
  Q：双击后命令行一闪而过 / 闪退？
  A：多半是 Python 没装或没加入 PATH。先装 Python 3.10+，
     安装时务必勾选「Add python.exe to PATH」。

  Q：提示 can't open file / 找不到 install_helper.py？
  A：说明你是在压缩包里直接双击的。请按本文第一步完整解压后再运行。

  Q：扫码后页面加载失败？
  A：服务运行在独立窗口，关掉「启动器」窗口不影响它。
     若仍打不开，确认服务窗口还开着，或双击 start.bat 重启服务。
